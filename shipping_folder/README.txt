Red Fractal is a real time fractal explorer that
lets you get a deep dive into the misterious world of
fractal shapes. It offers great precision, utilizes
cpu multithreading and allows you to take snapshots.
Thank you for installing our application.


How to run Red Fractal:

- The executable is located inside the bin folder and 
  is named Red_Fractal.exe. Double click it to run it 
  or create a desktop shortcut for easy access.

- Deleting or moving any file inside this folder 
  could result in software corruption.


Controls:

- Mouse                 Navigate Menu
- Arrow keys / wasd     Move Camera
-   Z                   Zoom in
-   X                   Zoom out
-   S                   Snapshot
- Escape                Main menu

Note: every snapshot you take will be stored
inside the snapshots folder.
